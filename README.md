
# Personal Portfolio Website

A personal portfolio website created to showcase my education, technical skills, projects, and learning journey as a B.Tech Computer Science and Engineering (AI & ML) student.

## Live Website

[View My Portfolio](https://priti-kumari-portfolio.vercel.app/)

## Technologies Used

- HTML5 — Page structure and content
- CSS3 — Styling, layout, and responsive design
- JavaScript — Interactive functionality
- Git & GitHub — Version control
- Vercel — Website deployment

## Features

- Responsive layout for desktop and mobile devices
- Sections for education, technical skills, and projects
- Navigation between portfolio sections
- Links to GitHub and LinkedIn
- Project showcase featuring CivicFix

## Featured Project

### CivicFix

A civic issue reporting and tracking web application currently under development.

The project explores frontend development, backend APIs, database integration, and complaint management.

[View CivicFix on GitHub](https://github.com/pritik16/CivicFix)

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/pritik16/Portfolio.git
   ```

2. Open the `Portfolio` folder.
3. Open `index.html` in a web browser.

No backend server or database is required for this portfolio website.
